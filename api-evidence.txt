SpellCooldownInfo.isEnabled/isActive are NeverSecret; startTime/duration are not.
isOnGCD is NeverSecret but only trustworthy in SPELL_UPDATE_COOLDOWN context.
GetSpellCooldownDuration accepts ignoreGCD and returns a duration object for native display.
IsSpellUsable supplies usability and insufficient power; neither has a NeverSecret annotation: guard both.
IsSpellInRange can return nil for invalid checks. UnitPower is secret when restricted.
