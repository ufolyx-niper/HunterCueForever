# HunterCue Forever

独立的 WoW Forever 猎人提示插件，包含兽王、射击、生存 weaving。**不需要 MaxDps 或 WeakAuras**，不会替你施法、移动或选目标。

## 安装或更新

WowUp 选择 **Forever** →「从 URL 安装」，使用本仓库地址：

`https://github.com/ufolyx-niper/HunterCueForever`

手动安装：在[最新 Release](https://github.com/ufolyx-niper/HunterCueForever/releases/latest)下载 `HunterCueForever-1.2.0-forever.zip`，将其中的 `HunterCueForever` 文件夹放到 `_forever_/Interface/AddOns/`。**更新后重启游戏**，确保新增文件加载。不要把自动生成的 Source code ZIP 当安装包。

## 战斗界面

默认只有选中存活的敌对非玩家目标才显示 HUD。登录不自动打开设置，没有目标时也不会常驻一块“专精自动、均衡、单体”的控制面板。

- **大图标**：常规循环的下一技能。默认开启固定推荐，选定后不会因为普通优先级变化一直来回换。
- **“已施放 / 确认下一技能”**：刚施法后的短暂状态同步，不是在让你重复按刚才的技能。
- **“预告 / 还需 X 秒”**：当前没有合适的主动技能，下一技能还在冷却。保持自动射击，等它就绪；不是催你提前按。更早出现真正可用的技能时会更新。
- **下方小图标**：巨魔「狂暴」、急速射击、兽王「狂野怒火」分开提示，**自身冷却中完全隐藏**；未学会、不满足使用条件或状态未知时也不显示。仅有公共 CD 不会让就绪提醒跟着闪烁，实际施放仍服从游戏限制。
- **生存走位文字**：提醒进出近战，移动始终由玩家完成。需要自己开启近战自动攻击。

每个已启用、已学会的爆发技能有自己的固定槽位。一个技能进入冷却后隐藏，其他图标不会滑来滑去。爆发提示不替换你准备按的常规大图标。

默认隐藏详细减益和资源状态；需要时在设置开启“显示详细状态”。正常 HUD 没有常驻的编辑说明或配置按钮，战斗中鼠标可穿过它。

## 固定推荐如何工作

公共 CD 内，已识别的施法成功后用约 **0.2–0.35 秒**等待状态更新（覆盖刚施法的同步保护窗口），然后选定下一技能；公共 CD 结束后再保留约 **0.35 秒**给你准备按键。单次固定最长 **2.5 秒**，防止漏事件导致一直卡住。已可继续行动时不额外停顿：同步保护结束前可显示当前可用技能，但不会过早把临时的填充建议固定住。

**仍需纠正的情况**包括切目标、目标死亡、原技能不能使用或不够蓝、射程变化、移动使读条技能不可用、已开始施法/引导、改变模式等。普通新触发/优先级变化不会抢走仍有效的固定技能；这会偏向操作稳定，可能让少量理论极限输出让步。

数秒空档时，最多预看 **6 秒**内、符合当前策略的冷却技能。预告到就绪尽量保持同一图标；当前实际可用的动作优先于未来预告。不会为填满每个公共 CD 而强迫使用被省蓝策略排除的技能。

**Forever 可能在战斗中限制冷却数值。** 数字不可读时不会编造秒数或假装知道谁先冷却；显示自动射击/等待。施法事件的技能 ID 不可读时，也无法精确识别刚施放的技能；会用可读的公共 CD 变化和时间上限防止长期停留。无法保证所有受限场景都无切换。

设置中取消“公共 CD 内固定下一技能”即可实时更新。共同的冷却判断和防止立即重复补钉刺的修正仍保留，不会退回旧版问题。

## 设置入口与布局

**`/hcf`**、**ESC → 选项 → 插件 → HunterCue Forever**，或**脱战时右键大图标**打开真正的设置页。隐藏 HUD 后仍可用前两个入口找回。原生设置接口不可用时使用独立窗口，Escape 可关闭。

设置分为外观/位置、常规循环、爆发栏：

| 选项 | 范围 / 默认 |
|---|---|
| 整体大小 | 60–200%，默认100% |
| 提示文字大小 | 90–125%，默认100% |
| 背景不透明度 | 20–100%，默认92%；文字不变淡 |
| 显示条件 | 有敌对目标 / 仅战斗 / 始终；默认有敌对目标 |
| 详细状态文字 | 默认关闭 |
| 固定下一技能 | 默认开启 |
| 爆发栏 | 总开关及狂暴、急速射击、狂野怒火各自开关 |
| 陷阱 | 默认关闭，避免破坏控场 |

位置可用 X/Y、方向微调、居中调整。**拖动需先打开脱战预览并解除锁定**，然后拖动预览面板。关闭设置或进入战斗会退出预览；未完成的拖动取消，不覆盖原位置。窗口临时变小只限制显示范围，恢复大小后回到原坐标。

“重置布局”只改位置、大小、文字与背景；“重置全部设置”需要确认。设置即时生效，按角色保存。声音没有加入，避免持续循环提示反复打扰。

**升级提示：**第一次从1.0/1.1升级，会将旧版“始终显示”改为“有敌对目标时显示”，其他显隐条件和关闭状态保留。旧版无法区分“默认始终”和“你曾手选始终”；如需常驻可改回，之后会保留。位置迁移仍保留原有缩放坐标语义。

## 配置三系

- **兽王**：雄鹰 / 雄鹰 / 奥术序列及适合的瞄准填充；省蓝减少瞄准。自行命令宠物攻击，爆发栏中狂野怒火需要存活宠物。
- **射击**：均衡/全力使用奥术、瞄准、狙击；省蓝减少瞄准。参考模拟使用孤狼收宠天赋，插件不会替你收宠或改天赋。
- **生存 weaving**：设置里选择常规或积极穿插。常规保留瞄准窗口；积极更偏近战穿插。射程和射击时机不可靠时会提示手动判断，不声称零损失穿插。

守护、强击光环、饰品、药水等仍由你自行安排。印记/钉刺的“等待生效确认”和“估时”不等于实际命中：已确认同目标施法后最多等待2秒；之后按真实可读减益和连续未生效的暂缓机制处理。切目标不会把上一目标的估时带过来。

## 战斗快捷切换

配置放在设置页，战斗中可直接使用命令；也可自己把下面两行分别做成动作条宏（插件不会自动创建或执行宏）：

```text
/hcf targets next
```

在单体、3+、6+目标之间循环。面对控场目标用单体。

```text
/hcf mode next
```

在均衡、省蓝、全力之间循环。“全力”是资源策略，和爆发栏的显示开关是两回事。

| 命令 | 用途 |
|---|---|
| `/hcf` / `/hcf config` | 打开设置 |
| `/hcf spec auto` / `bm` / `mm` / `sv` | 自动 / 兽王 / 射击 / 生存 |
| `/hcf mode balanced` / `conserve` / `burst` | 选择资源策略 |
| `/hcf targets 1` / `3` / `6` | 选择目标数类别 |
| `/hcf stable on` / `off` | 固定 / 实时推荐 |
| `/hcf weave normal` / `aggressive` | 生存常规 / 积极穿插 |
| `/hcf burst on` / `off` | 爆发栏总开关；各技能开关在设置页 |
| `/hcf traps on` / `off` | 陷阱提示 |
| `/hcf show` / `hide` | HUD 总开关，仍受显示条件限制 |
| `/hcf lock` | 预览拖动锁定开关 |
| `/hcf pos 180 -130` / `/hcf scale 1.2` | 脱战调整位置 / 大小 |
| `/hcf reset` | 打开设置并请求确认重置 |
| `/hcf status` / `/hcf help` | 诊断 / 命令帮助 |
