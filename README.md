# HunterCue Forever

独立的 WoW Forever 猎人提示插件，包含兽王、射击、生存 weaving。**不需要 MaxDps 或 WeakAuras**，不会替你施法、移动或选目标。

## 安装或更新

WowUp 选择 **Forever** →「从 URL 安装」，使用本仓库地址：

`https://github.com/ufolyx-niper/HunterCueForever`

手动安装：在[最新 Release](https://github.com/ufolyx-niper/HunterCueForever/releases/latest)下载 `HunterCueForever-1.7.0-forever.zip`，将其中的 `HunterCueForever` 文件夹放到 `_forever_/Interface/AddOns/`。**更新后重启游戏**，确保新增文件加载。不要把自动生成的 Source code ZIP 当安装包。

## 纯图标 HUD

**没有背景板、常驻外框、技能名称、说明文字、爆发标签、预览文字或倒计时数字。** 爆发就绪和“值得补毒蛇”可使用原生按钮发光效果，均可单独关闭。 鼠标悬停也不会弹出 HUD 说明。设置页和 `/hcf help` 保留文字帮助。

- 三个独立区域：主推荐、爆发/猎人印记整组、毒蛇监控。辅助提醒不占主推荐图标，平射也不会常驻主图标。
- 自身冷却中的爆发图标完全隐藏；优先使用客户端“忽略公共 CD”的自身冷却查询，保留能确认就绪的爆发提醒。
- 主图标等待或同步时变灰，保留原生冷却转圈；没有可确认的建议时不显示主图标，不用问号或文字占位。
- 爆发/印记共用一个位置，整组拖动。冷却时隐藏图标但保留槽位，其他图标不会跳位；在设置中关闭或尚未学会的技能不占槽位。
- 默认没有敌对目标时隐藏；登录不自动打开设置。图标只提醒，不替你施法、移动或选目标。

稳定推荐和空档预告：公共 CD 内选定后保持，结束后保留约0.35秒输入时间；同步期间不会过早固定临时结果。切目标、技能失效等情况仍会纠正。已确认到期的兽王核心技能会替换瞄准填充，射击的奥术/瞄准也会替换狙击填充，避免为了固定图标延误核心技能。界面不再把原因、秒数或生存走位提示写在 HUD 上；你需自行掌握进退，进入对应射程后仍按该系优先级推荐。

**提前推荐按下一次可行动的时刻判断。** 技能能在当前 GCD 结束前转好时，提前进入推荐；瞄准、狙击等读条期间，若施法和冷却时间可读，也会提前显示下一技能的灰色预告。灰色表示等当前读条/GCD结束，**不要为了预告打断当前施法**。预测会排除当前施法及其共享冷却技能，并在蓝量可读时保守预留当前读条的蓝耗。引导或时间不可读时不猜测；这不保证所有客户端受限状态都能提前显示。

## 设置入口与位置大小

输入 **`/hcf`**、使用 **ESC → 选项 → 插件 → HunterCue Forever**，或**脱战右键主推荐或爆发/印记图标**打开设置。HUD 隐藏时仍可通过前两个入口找回。

| 选项 | 范围 | 新安装默认 |
|---|---:|---:|
| 主推荐图标大小 | 24–160 px | 56 px |
| 爆发/印记组内统一图标大小 | 12–96 px | 32 px |
| 爆发/印记组内图标间隔 | 0–40 px | 8 px |
| 爆发/印记组展开方向 | 向右 / 向左 | 向右 |
| 爆发就绪发光 | 开 / 关 | 开 |
| 值得补毒蛇时发光 | 开 / 关 | 开 |

这里的 px 是游戏界面单位。**爆发和猎人印记是一整组，不再逐个拖动。** 主推荐和毒蛇仍各自独立；全程没有背景面板。

脱战输入 **`/hcf` →「解锁并定位」**，设置收起后拖动主图标、爆发组或毒蛇。拖爆发组内任意预览图标或组内空隙，整组一起移动。松开保存，点屏幕上方「完成定位」退出。关闭设置不会结束定位；进入战斗会退出并取消未完成拖动。登录/重载不自动预览。

**组内大小、间隔、展开方向调整后立即生效，不需要再点排列。** 组起点是第一个已启用且已学会图标的中心，改变展开方向时起点保持不变；顺序是狂暴、急速射击、狂野怒火、猎人印记。「整组移到主图标下方」只是一个位置快捷操作。移动主图标不会带动爆发组。

主图标和毒蛇位置保留。爆发组有独立 X/Y；升级时以旧版第一项已启用且已学会的小图标位置作为组起点，一次性迁移，尺寸/间隔保留。战斗中技能扫描未完成时等待脱战迁移。旧单图标坐标仅保留作兼容，不再控制组内图标。

「重置布局」恢复三个区域的位置、尺寸、组间隔和向右展开，保留循环偏好与发光开关；「重置全部」需再次确认。配置按角色保存。屏幕较小时会限制整组位置或缩小显示，但保留保存坐标。

## 毒蛇钉刺：独立监控与旧插件迁移

合并了 Serpent Sting Hint 0.1.4 的监控和定位流程；**请停用原 `SerpentStingHint`，更新后重启游戏**。不用卸载或删除旧配置。若旧插件仍启用，HunterCue 会暂停内置毒蛇监控并在设置中说明，避免两套同时提醒。合并版独立保存选项，不自动读取已停用插件的配置；旧版自定义门槛需在 `/hcf` 的毒蛇区域重新设置。

| 毒蛇图标状态 | 意义 |
|---|---|
| 灰色图标 + 原生冷却转圈 | 当前目标身上已有你施放的毒蛇钉刺 |
| 亮色图标，默认带按钮发光 | 缺少你的钉刺，且符合存活时间或开怪血量规则，值得考虑施放 |
| 隐藏 | 没有补钉刺提示，也没有正在监控的钉刺；或该模块/整体显隐条件不满足 |

**毒蛇发光沿用原来的“值得补”条件，绝不是目标没有毒蛇就发光。** 没有你的毒蛇，但既不满足有效存活时间估算、也不满足开怪血量规则时，不触发发光；被元素过滤或没有有效敌对目标时也不触发。低血量不是全程硬性禁止：若已有可靠样本表明仍能存活足够久，仍按原规则提示。已有你施放的毒蛇时只显示正常减益监控。关闭「值得补毒蛇时发光」只关闭动画，符合条件时仍保留原来的亮色提示图标。

可选「没有补钉刺提示时保留灰色图标」，默认关闭。主图标不会再推荐毒蛇，手动施放也不会把毒蛇放进主图标的同步占位。

- 独立大小 **16–128 px，默认44**；位置默认 X140、Y-100。
- 预计剩余击杀时间门槛 **1–60秒，默认10**；掉血估算至少需要3次受伤事件、2秒观察及足够的掉血。5秒没有新受伤事件会丢弃旧估计。
- 开怪血量规则默认启用，**当前剩余血量至少5000**；可调整1–10000000点。目标开始战斗或首次受伤后的6秒内，在估算样本不足时使用。最大血量不可读时不猜测门槛结果。
- 可跳过元素生物的补钉刺提示；默认关闭。这按类别判断，不是免疫检测，已存在的钉刺仍正常监控。
- 监控当前存活的敌对目标，包括敌对玩家；常规循环仍按原来的 PvE 目标规则运行。全局显隐也适用于毒蛇。

减益状态和冷却转圈由游戏原生减益容器绘制，不把成功施法当作确认命中；补钉刺图标是独立辅助，**不代表射程、蓝量、公共CD均已满足**。掉血估算会受治疗、集火变化和阶段转换影响。若客户端缺少原生减益接口，设置会说明该监控不可用，常规循环继续工作。原生发光模板不可用时退回普通图标提示；发光的真实渲染和帧率尚未进行游戏内实测。

## 猎人印记：独立辅助，不进入常规循环

**猎人印记不会出现在主推荐图标中，也不会因未上印记卡住常规输出。** 它位于爆发/印记组中，与爆发一起移动，但提醒条件仍由“猎人印记”区域独立控制，不受爆发总开关影响，也不参与爆发发光。

推荐默认：

- 范围为 **精英 / 首领**，普通怪不提醒。
- **只在开怪前提醒**：玩家和目标都尚未战斗时才亮，避免战斗切目标时催促你改标。
- 目标已有任何猎人的印记、状态未知、估时未确认、正在等待生效、超出射程或技能不能使用时不亮。

可改成“所有敌对目标”，开启“战斗中也提醒”，或完全关闭。只提醒当前目标；**不会自动转移或覆盖印记，也不要求每只怪都上**，你自己决定唯一的印记留给谁。默认规则不预测目标剩余寿命，低血量精英也可能在开怪前触发提醒。

如果把整个 HUD 设为“仅战斗显示”，默认的开怪前印记提醒也会被隐藏；设置页会说明这个组合。希望看到它可选择“有敌对目标时显示”，或自行允许战斗中提醒。Forever 不允许读取减益/目标类型时会保守隐藏，而不是强行提示。

## 爆发栏与常规提示

巨魔狂暴、急速射击、狂野怒火各有开关；默认就绪时发光，可关闭「爆发就绪时发光」。优先查询忽略公共 CD 后的自身冷却；接口不可用或结果受限时，使用可确认的旧判断回退。真正的自身冷却不会被“快转好”的预测当作就绪，成功施放后会立即隐藏。狂野怒火还要求宠物存活。

公共 CD 期间，只要能确认自身冷却已好且不是资源不足，临时的“不可用”不会单独让爆发图标消失。图标是冷却就绪提醒，不保证此刻可施放；如果还有其他临时限制，它可能在 GCD 内保留、GCD 外隐藏。资源状态不可读（包括接口未返回缺蓝状态）时保守隐藏。印记继续按原有即时可用性规则判断，可能在公共 CD 期间隐藏。

`/hcf status` 会输出每个爆发使用的是原生自身冷却、备用判断，还是资源/宠物等限制，便于定位实际客户端差异。离线验证不代表已确认你的游戏客户端行为。

设置里可关闭“固定下一技能”改成实时更新。固定建议在阶段、范围、移动、资源预算或目标改变时仍会纠正；确认到期的兽王核心技能可替换瞄准填充，射击的奥术/瞄准可替换狙击填充。其他仍有效的固定技能保留原规则。固定和预告都有时间上限，不是整场固定序列。接口隐藏冷却数值时不伪造未来时刻。

## 配置三系

- **兽王**：正常按“两鹰一奥术”推进，只由玩家实际成功施放推进阶段，不再要求老鹰还剩超过6.2秒。切目标、普通技能重扫和公共CD读不到时间，不会清空阶段或催补鹰。参考HawkTimer的事件跟踪思路，优先使用可读的雄鹰槽位/期限；无法读到时保留有界估算，不把未知当作消失。飞行未确认超过5秒时回退到施放后18秒估算。确认消失或估算到期才修正记录；替换老鹰和新鹰飞行不会重复扣数。
- **射击 / 孤狼**：保留奥术、瞄准、狙击填充的优先级；省蓝模式减少瞄准。在 `/hcf` 设置底部可关闭「射击：允许狙击填充」（默认开启）。缺蓝的长战斗可关闭比较；短战斗、团队增益和装备会影响结果，没有一个开关状态适合所有场景。手动收宠以启用孤狼，插件不会替你收宠或改天赋。狙击的独立射程不会再被奥术/平射的射程否决。
- **生存 weaving**：常规穿插在可用的瞄准即将于下一行动后 0.5 秒内转好时，会等待并预告瞄准，避免奥术占用 GCD；移动、射程不符或瞄准不可用时不盲等。积极模式仍偏瞬发。进入近战超过 1.5 秒后，不再催促新的近战技能；若猛禽已排队，仍应等它挥出再退。纯图标不显示走位文字，也不自动移动或取消猛禽队列。

### 雄鹰估时与蓝量保护

雄鹰不是玩家常驻宠物。槽位资料可读时使用可确认的期限，读取受限时使用召唤事件和施放时间估算，最多两只分别记录；奥术不会清空记录。普通切目标、技能重扫、假死与有效缓存重载会保留阶段；实际死亡、确认遗失或已知期限结束才修正。`/hcf hawks` 区分原生期限、事件推断、施放估算和缓存，不把估算冒充存活确认。

实时推荐、固定推荐、空档预告和读条预告共用相同条件。预告会推算技能冷却、检查资源、射程和策略，不会凭预告虚构一次雄鹰或奥术施放；实际阶段改变、确认消失、蓝量不足等情况会及时纠正已固定图标。

雄鹰跟踪是全局召唤与施放阶段，不是“当前目标上有几只鹰”的保证：鹰可能仍攻击旧目标，焦点/鼠标指向施放也会推进全局阶段。重载使用经时钟校验的角色缓存；有两只鹰但历史失效时，不能区分刚放完第二只还是刚打完奥术，此时不猜测鹰/奥术，由下一次实际施放或消失确认恢复。`/hcf hawks` 可立即复查并显示阶段、来源和剩余估时。完全不支持槽位读取时，提前死亡只能等估算到期；并非实时存活保证。

自动专精在切换副天赋后重新读取已学技能。短暂读取失败会重试，普通战斗中的延迟重扫不会停掉当前循环；持续部分受限时只采用确认学会的技能，无法确定专精则使用通用远程建议并避免猜测雄鹰共享CD。可在设置手动选择「射击」；`/hcf status` 可查看扫描诊断。

均衡/省蓝的远程循环会按候选技能的真实可读蓝耗计算，并为该专精/目标数量下的核心技能留蓝。**毒蛇监控启用且毒蛇缺失、临近结束或状态不明时，仍预留其蓝耗**；独立图标不代表不需要它。确认毒蛇仍有余量或关闭毒蛇监控后，可释放这部分预留。这只是资源预算，不会出现第二套毒蛇提示；接口受限时预算可能偏保守。全力模式放宽预留和百分比门槛，但不会推荐已知蓝量支付不起的技能。

守护、强击光环、饰品、药水等仍由你自行安排。印记提示在施法后最多有2秒生效等待；这不等于确认命中。毒蛇显示使用上述独立监控，切目标重新采样。

## 战斗快捷切换

配置放在设置页，战斗中可直接使用命令；也可自己把下面两行分别做成动作条宏（插件不会自动创建或执行宏）：

```text
/hcf targets next
```

在单体、3+、6+目标之间循环。面对控场目标用单体。

```text
/hcf mode next
```

在均衡、省蓝、全力之间循环。“全力”是资源策略，和爆发栏的显示开关是两回事。

| 命令 | 用途 |
|---|---|
| `/hcf` / `/hcf config` | 打开设置 |
| `/hcf spec auto` / `bm` / `mm` / `sv` | 自动 / 兽王 / 射击 / 生存 |
| `/hcf mode balanced` / `conserve` / `burst` | 选择资源策略 |
| `/hcf targets 1` / `3` / `6` | 选择目标数类别 |
| `/hcf stable on` / `off` | 固定 / 实时推荐 |
| `/hcf weave normal` / `aggressive` | 生存常规 / 积极穿插 |
| `/hcf burst on` / `off` | 爆发栏总开关；各技能开关在设置页 |
| `/hcf traps on` / `off` | 陷阱提示 |
| `/hcf show` / `hide` | HUD 总开关，仍受显示条件限制 |
| `/hcf lock` | 预览拖动锁定开关 |
| `/hcf pos 36 -80` | 脱战调整主图标中心位置；大小和间距在设置页独立调整 |
| `/hcf reset` | 打开设置并请求确认重置 |
| `/hcf status` / `/hcf hawks` / `/hcf help` | 状态诊断 / 雄鹰复查 / 命令帮助 |

离线测试还覆盖逐只雄鹰期限、前瞻时间推进、三系共享资格检查、省蓝/毒蛇预留、射程探测合并（相互矛盾时保留未知）、近战排队边界和目标最大血量变化。事件时间线对比不是伤害模拟，没有据此宣称 DPS 提升。离线测试包含 Lua5.1、推荐时间序列、纯图标结构、三个区域与整组位置迁移/拖动/屏幕适配、关闭设置后继续编辑、战斗退出、独立印记、毒蛇原生接口注册/健康曲线转交、旧插件冲突、登录显隐及安装包检查。Mock 检查接口连接和逻辑，不能证明真实客户端原生裁剪或转圈的渲染效果。**尚未进行真实客户端的新界面、受限数据和实战验收**。模拟策略不等于本插件的实战DPS保证；移动/网络/客户端限制仍会影响提示。
