# HunterCue Forever

独立的 WoW Forever 猎人提示插件，包含兽王、射击、生存 weaving。**不需要 MaxDps 或 WeakAuras**，不会替你施法、移动或选目标。

## 安装或更新

WowUp 选择 **Forever** →「从 URL 安装」，使用本仓库地址：

`https://github.com/ufolyx-niper/HunterCueForever`

手动安装：在[最新 Release](https://github.com/ufolyx-niper/HunterCueForever/releases/latest)下载 `HunterCueForever-1.4.1-forever.zip`，将其中的 `HunterCueForever` 文件夹放到 `_forever_/Interface/AddOns/`。**更新后重启游戏**，确保新增文件加载。不要把自动生成的 Source code ZIP 当安装包。

## 纯图标 HUD

**没有背景板、外框、技能名称、说明文字、爆发标签、预览文字或倒计时数字。** 鼠标悬停也不会弹出 HUD 说明。设置页和 `/hcf help` 保留文字帮助。

- 主图标提示常规循环；爆发、印记和毒蛇各自独立，不占主推荐图标。平射不会常驻主图标。
- 自身冷却中的爆发图标完全隐藏；优先使用客户端“忽略公共 CD”的自身冷却查询，保留能确认就绪的爆发提醒。
- 主图标等待或同步时变灰，保留原生冷却转圈；没有可确认的建议时不显示主图标，不用问号或文字占位。
- 每个图标独立保存位置。某个技能冷却、关闭或尚未学会时隐藏，其他图标不移动。
- 默认没有敌对目标时隐藏；登录不自动打开设置。图标只提醒，不替你施法、移动或选目标。

稳定推荐和空档预告的计算保持原有规则：公共 CD 内选定后保持，结束后保留约0.35秒输入时间；同步期间不会过早固定临时结果。切目标、技能失效等情况仍会纠正。界面不再把原因、秒数或生存走位提示写在 HUD 上；你需自行掌握进退，进入对应射程后仍按该系优先级推荐。

**提前推荐按下一次可行动的时刻判断。** 技能能在当前 GCD 结束前转好时，提前进入推荐；瞄准、狙击等读条期间，若施法和冷却时间可读，也会提前显示下一技能的灰色预告。灰色表示等当前读条/GCD结束，**不要为了预告打断当前施法**。预测会排除当前施法及其共享冷却技能，并在蓝量可读时保守预留当前读条的蓝耗。引导或时间不可读时不猜测；这不保证所有客户端受限状态都能提前显示。

## 设置入口与位置大小

输入 **`/hcf`**、使用 **ESC → 选项 → 插件 → HunterCue Forever**，或**脱战右键主推荐或爆发/印记图标**打开设置。HUD 隐藏时仍可通过前两个入口找回。

| 选项 | 范围 | 新安装默认 |
|---|---:|---:|
| 主推荐图标大小 | 24–160 px | 56 px |
| 下方提醒图标大小（爆发与印记） | 12–96 px | 32 px |
| 一键排列时的横向间隔 | 0–40 px | 8 px |
| 一键排列时距主图标的距离 | 0–80 px | 12 px |

这里的 px 是游戏界面单位。主推荐、狂暴、急速射击、狂野怒火、猎人印记、毒蛇监控均为**独立的图标窗口**；没有背景，也不会因别的图标移动而跟随。

**脱战输入 `/hcf` →「解锁并定位」**：设置窗口收起，屏幕上方保留编辑按钮。逐个拖动图标，松开即保存；关闭设置不会退出定位。点「完成定位」退出。进入战斗会结束预览并取消未完成的拖动。重载后不会自动开启预览。设置关闭时仍能通过上方按钮解锁/锁定、重新打开设置。

「一键排列小图标」会按照横向间隔、上下距离，把已启用且已学会的爆发/印记排到主图标下方。**间隔设置用于这次排列；点击排列才应用。**之后每个图标仍可单独拖动。改变主图标位置或图标大小不会重新排列其他图标。毒蛇保持自己的位置。

主图标还支持 X/Y、方向微调、居中；毒蛇也有独立 X/Y 和大小。屏幕边缘会限制显示位置，但保留保存坐标。「重置布局」恢复全部图标位置、大小和间隔，保留循环/监控偏好；「重置全部」需再次确认。配置按角色保存。升级从旧版整组布局一次性换算为独立小图标坐标，之后重载不会重新排列。

## 毒蛇钉刺：独立监控与旧插件迁移

合并了 Serpent Sting Hint 0.1.4 的监控和定位流程；**请停用原 `SerpentStingHint`，更新后重启游戏**。不用卸载或删除旧配置。若旧插件仍启用，HunterCue 会暂停内置毒蛇监控并在设置中说明，避免两套同时提醒。合并版独立保存选项，不自动读取已停用插件的配置；旧版自定义门槛需在 `/hcf` 的毒蛇区域重新设置。

| 毒蛇图标状态 | 意义 |
|---|---|
| 灰色图标 + 原生冷却转圈 | 当前目标身上已有你施放的毒蛇钉刺 |
| 亮色图标 | 缺少你的钉刺，且符合存活时间或开怪血量规则，值得考虑施放 |
| 隐藏 | 没有补钉刺提示，也没有正在监控的钉刺；或该模块/整体显隐条件不满足 |

可选「没有补钉刺提示时保留灰色图标」，默认关闭。主图标不会再推荐毒蛇，手动施放也不会把毒蛇放进主图标的同步占位。

- 独立大小 **16–128 px，默认44**；位置默认 X140、Y-100。
- 预计剩余击杀时间门槛 **1–60秒，默认10**；掉血估算至少需要3次受伤事件、2秒观察及足够的掉血。5秒没有新受伤事件会丢弃旧估计。
- 开怪血量规则默认启用，**当前剩余血量至少5000**；可调整1–10000000点。目标开始战斗或首次受伤后的6秒内，在估算样本不足时使用。最大血量不可读时不猜测门槛结果。
- 可跳过元素生物的补钉刺提示；默认关闭。这按类别判断，不是免疫检测，已存在的钉刺仍正常监控。
- 监控当前存活的敌对目标，包括敌对玩家；常规循环仍按原来的 PvE 目标规则运行。全局显隐也适用于毒蛇。

减益状态和冷却转圈由游戏原生减益容器绘制，不把成功施法当作确认命中；补钉刺图标是独立辅助，**不代表射程、蓝量、公共CD均已满足**。掉血估算会受治疗、集火变化和阶段转换影响。若客户端缺少原生接口，设置会说明该监控不可用，常规循环继续工作。

## 猎人印记：独立辅助，不进入常规循环

**猎人印记不会出现在主推荐图标中，也不会因未上印记卡住常规输出。** 它作为下方独立的小图标，由设置中的“猎人印记”区域控制，不受爆发栏总开关影响。

推荐默认：

- 范围为 **精英 / 首领**，普通怪不提醒。
- **只在开怪前提醒**：玩家和目标都尚未战斗时才亮，避免战斗切目标时催促你改标。
- 目标已有任何猎人的印记、状态未知、估时未确认、正在等待生效、超出射程或技能不能使用时不亮。

可改成“所有敌对目标”，开启“战斗中也提醒”，或完全关闭。只提醒当前目标；**不会自动转移或覆盖印记，也不要求每只怪都上**，你自己决定唯一的印记留给谁。默认规则不预测目标剩余寿命，低血量精英也可能在开怪前触发提醒。

如果把整个 HUD 设为“仅战斗显示”，默认的开怪前印记提醒也会被隐藏；设置页会说明这个组合。希望看到它可选择“有敌对目标时显示”，或自行允许战斗中提醒。Forever 不允许读取减益/目标类型时会保守隐藏，而不是强行提示。

## 爆发栏与常规提示

巨魔狂暴、急速射击、狂野怒火各有开关。优先查询忽略公共 CD 后的自身冷却；接口不可用或结果受限时，使用可确认的旧判断回退。真正的自身冷却不会被“快转好”的预测当作就绪，成功施放后会立即隐藏。狂野怒火还要求宠物存活。

公共 CD 期间，只要能确认自身冷却已好且不是资源不足，临时的“不可用”不会单独让爆发图标消失。图标是冷却就绪提醒，不保证此刻可施放；如果还有其他临时限制，它可能在 GCD 内保留、GCD 外隐藏。资源状态不可读（包括接口未返回缺蓝状态）时保守隐藏。印记继续按原有即时可用性规则判断，可能在公共 CD 期间隐藏。

`/hcf status` 会输出每个爆发使用的是原生自身冷却、备用判断，还是资源/宠物等限制，便于定位实际客户端差异。离线验证不代表已确认你的游戏客户端行为。

设置里可关闭“固定下一技能”改成实时更新。普通优先级变化不会抢走仍有效的固定技能，但范围、移动、资源不足、目标变化等真实失效会纠正。固定和预告都有时间上限，不是整场固定序列。接口隐藏冷却数值时不伪造未来时刻。

## 配置三系

- **兽王**：雄鹰 / 雄鹰 / 奥术序列及适合的瞄准填充；省蓝减少瞄准。自行命令宠物攻击，爆发栏中狂野怒火需要存活宠物。
- **射击**：均衡/全力使用奥术、瞄准、狙击；省蓝减少瞄准。参考模拟使用孤狼收宠天赋，插件不会替你收宠或改天赋。
- **生存 weaving**：设置里选择常规或积极穿插。常规保留瞄准窗口；积极更偏近战穿插。纯图标不显示走位文字，你需手动进出近战；不声称零损失穿插。

守护、强击光环、饰品、药水等仍由你自行安排。印记提示在施法后最多有2秒生效等待；这不等于确认命中。毒蛇显示使用上述独立监控，切目标重新采样。

## 战斗快捷切换

配置放在设置页，战斗中可直接使用命令；也可自己把下面两行分别做成动作条宏（插件不会自动创建或执行宏）：

```text
/hcf targets next
```

在单体、3+、6+目标之间循环。面对控场目标用单体。

```text
/hcf mode next
```

在均衡、省蓝、全力之间循环。“全力”是资源策略，和爆发栏的显示开关是两回事。

| 命令 | 用途 |
|---|---|
| `/hcf` / `/hcf config` | 打开设置 |
| `/hcf spec auto` / `bm` / `mm` / `sv` | 自动 / 兽王 / 射击 / 生存 |
| `/hcf mode balanced` / `conserve` / `burst` | 选择资源策略 |
| `/hcf targets 1` / `3` / `6` | 选择目标数类别 |
| `/hcf stable on` / `off` | 固定 / 实时推荐 |
| `/hcf weave normal` / `aggressive` | 生存常规 / 积极穿插 |
| `/hcf burst on` / `off` | 爆发栏总开关；各技能开关在设置页 |
| `/hcf traps on` / `off` | 陷阱提示 |
| `/hcf show` / `hide` | HUD 总开关，仍受显示条件限制 |
| `/hcf lock` | 预览拖动锁定开关 |
| `/hcf pos 36 -80` | 脱战调整主图标中心位置；大小和间距在设置页独立调整 |
| `/hcf reset` | 打开设置并请求确认重置 |
| `/hcf status` / `/hcf help` | 诊断 / 命令帮助 |
