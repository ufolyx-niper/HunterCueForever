# HunterCue Forever

WoW Forever 猎人循环提示：**兽王、射击、生存 weaving 三套集成在一个插件里**。独立运行，**不需要 MaxDps，也不需要 WeakAuras**。只显示建议，不替你施法、移动或选目标。

## 安装

在 WowUp 选择 **Forever** 客户端 →「从 URL 安装」，粘贴：

`https://github.com/ufolyx-niper/HunterCueForever`

手动安装：从 [最新 Release](https://github.com/ufolyx-niper/HunterCueForever/releases/latest) 下载 `HunterCueForever-1.1.0-forever.zip`。把里面的 `HunterCueForever` 文件夹放到 `_forever_/Interface/AddOns/`，重启游戏。不要下载 GitHub 自动生成的 Source code ZIP 当作安装包。

当前版本 1.1.0：已通过离线 Lua 5.1 测试与安装包检查，**尚未完成游戏内加载和实战验收**。1.60.1 / Interface 16001；只在猎人上启用。仓库与安装包不含个人角色姓名或军械库记录。

## 怎么用

登录猎人后，屏幕中间偏右下显示面板。拖动 HUD 标题调整位置；`/hcf lock` 锁定/解锁。没选敌人时显示待命。

战斗前仍需自行开启合适的守护、强击光环（如果学会），并命令宠物攻击。这些准备动作不由本插件代办。

- **专精**按钮循环切换自动、兽王、射击、生存。自动按学会的狂野怒火、Strider Kick、狙击射击识别；没有这些标志技能时用基础兽王规则，升级中或混合天赋请手选。
- **均衡 / 省蓝 / 全力**：均衡保留核心技能和适量填充；省蓝减少耗蓝填充；全力放宽蓝量保留。它们是资源策略，不会自动替你判断队伍回蓝或战斗结束时间。
- **单体 / 3+ / 6+ 目标**：自己选择。3+ 优先多重再乱射，6+ 优先乱射。面对控场怪请用单体；不会扫描并自动攻击其他目标。
- **大图标**是当前建议；公共冷却期间可显示下一个候选，等冷却后按。小图标是独立的爆发建议，不挤占正常输出。按自己的动作条/快捷键施放，图标不是施法按钮。
- **印记 / 钉刺文字**显示可确认的状态。标为「估时」时只根据确认的施法记录推算，不能保证命中、没有被驱散或命中的是同名目标；「未知」时请自行维持。未知状态不会把主循环卡在反复补钉刺上。
- 对同一目标连续两次施法后，仍能确认没有对应减益时，暂缓该提示20秒，避免主图标卡在免疫/抵抗目标上；这不等于识别了免疫原因，手动施法不受影响。
- **爆发开关**控制急速射击、兽王狂野怒火的小图标。**陷阱默认关闭**；手动打开后，仅生存近战窗口建议伤害陷阱，避免无意破控。
- **生存穿插设置（设置页）**：常规以远程技能窗口为主，近战打一轮后退；积极更侧重近战穿插，远程不填瞄准。初用推荐常规。移动始终由你控制。

### 各系要点

**兽王**：保持宠物存活并自行命令它攻击。提示召唤雄鹰、两次雄鹰后一次奥术，以及适合时的瞄准填充；省蓝模式省掉瞄准。这里记录的是施法序列，不是当前存活雄鹰的精确数量。长时间中断会重置序列。

**射击**：均衡/全力以奥术、瞄准、狙击组织输出；省蓝去掉瞄准填充。配套模拟使用孤狼收宠天赋，但插件**不会替你收宠或修改天赋**。其他天赋的最优性没有验证。

**生存 weaving**：远程出手后，在合适的窗口接近；进入近战后提示猫鼬触发、猛禽、Strider Kick，再提示撤回远程。猛禽已排队时等待挥击完成。需自行开启近战自动攻击。射程/冷却/自动射击事件不能可靠读取时，显示手动穿插说明，不声称精确掌握挥击时间；不保证零损失穿插。死区或超远距离会要求调整位置，不盲目让你向前或后退。

正在读条或引导时不会建议打断；移动时不提示需要站定施放的技能。

## 蓝量与限制

若客户端允许读取蓝量、回蓝速度和技能消耗，会根据当前蓝量及短期回蓝保留核心技能的资源。**受限时不会假装蓝量无限，也不会凭空报剩余百分比**，会显示「蓝量受限 · 手动省蓝」，按你选的模式继续给建议。没有实现秘密数值提取或精确击杀时间预测。

真实冷却快结束时，GCD 内的候选可能随着新事件重新排序；它不是模拟器那种知道未来的完整技能队列。若技能可用性也被客户端限制，显示「技能状态不可读」，请手动输出。

三系规则参考同装备 WoWSims 模拟，但**插件是适配可读取状态的实战提示，并非完整 APL 原样移植**。模拟器固定60级、固定增益/站位；不能拿模拟 DPS 当作本插件的实战保证，也不能推断任意装备、移动战或 PvP 的全局最优。研究参考 [WoWSims Forever](https://github.com/wowsims/forever/tree/00fecd9cff1be57483e21c061ed50d69748ae056)，不代表对任意装备都最优。

## 外观与设置

入口：**HUD 右上角“设置”**、**右键 HUD 标题**、**`/hcf`**，或者 **ESC → 选项 → 插件 → HunterCue Forever**。原生设置接口不可用时会打开独立设置窗口，可按 Escape 关闭。隐藏 HUD 后仍可通过 `/hcf` 找回。布局编辑和打开设置需脱战。

| 选项 | 范围 / 默认 | 效果 |
|---|---|---|
| 整体大小 | 60–200%，默认100% | 图标、按钮和面板一起缩放 |
| 提示文字大小 | 90–125%，默认100% | 单独调整技能名、原因、状态等文字 |
| 背景不透明度 | 20–100%，默认92% | 文字保持清晰，不随背景变淡 |
| 位置 | X/Y坐标、方向微调、居中、标题拖动 | 超出屏幕的部分自动限制；锁定后不能拖动 |
| 显示条件 | 始终 / 有敌对目标 / 仅战斗，默认始终 | 与“显示 HUD”总开关分别设置 |
| 脱战预览 | 默认关闭，不跨重载保存 | 无目标或 HUD 已隐藏时也能调整；关页或进战斗自动结束 |

小屏幕放不下时会自动缩小到可用空间，并在设置页说明实际大小。窗口临时变小时只调整显示位置，保留原始坐标，放大窗口后会恢复。`/hcf pos x y` 的坐标以 UIParent 为单位、相对屏幕中心；1.0 的缩放位置会自动迁移一次。

**重置布局**只恢复位置、整体大小、文字大小和背景，不改专精、循环或陷阱偏好。**重置全部设置**需要再点一次确认；关闭页面可取消。设置即时生效、按角色保存。声音没有加入：这是持续视觉提示，避免频繁打扰。

原 HUD 上的爆发、陷阱和穿插方式按钮已集中到设置页；HUD 保留最常用的专精、策略、目标数，减少战斗时误触。

## 命令

| 命令 | 用途 |
|---|---|
| `/hcf spec auto` / `bm` / `mm` / `sv` | 自动 / 兽王 / 射击 / 生存 |
| `/hcf mode balanced` / `conserve` / `burst` | 均衡 / 省蓝 / 全力 |
| `/hcf targets 1` / `3` / `6` | 目标数量类别 |
| `/hcf weave normal` / `aggressive` | 生存常规 / 积极穿插 |
| `/hcf burst on` / `off` | 爆发提示开关 |
| `/hcf traps on` / `off` | 陷阱提示开关 |
| `/hcf show` / `hide` | 显示 / 隐藏面板 |
| `/hcf lock` | 切换拖动锁定 |
| `/hcf pos 180 -130` | 相对屏幕中心的位置 |
| `/hcf reset` | 打开设置并请求确认重置全部 |
| `/hcf` / `/hcf config` | 打开设置 |
| `/hcf help` | 列出快捷命令 |
| `/hcf scale 1.2` | 脱战设置整体120%大小 |
| `/hcf status` | 版本、专精与接口可读性诊断，不输出私密状态 |

如果没有提示，先 `/hcf show`、选择存活的敌对非玩家目标，再检查专精；输出 `/hcf status`。支持中文技能名和已学技能等级。可和 EUI、HawkTimer 同时安装，但它们的提示可能重叠；MaxDps 非必需，建议关闭其猎人高亮，避免两套建议打架。
